# Python Data Analysis Project

## Overview
This project was completed as part of a **Data Technician Bootcamp** and focused on using **Python** and **pandas** to explore, clean, analyse, and visualise retail and sales datasets. The project involved working with real-world data to identify trends, handle missing values, transform datasets, and generate insights to support data-driven decision-making.

## Skills Demonstrated

### Data Exploration and Analysis
- Loaded and explored datasets using **pandas DataFrames**
- Examined dataset structure, columns, data types, and summary statistics
- Filtered and queried data using conditional statements
- Selected and analysed data using:
  - `.loc[]` for label-based indexing
  - `.iloc[]` for position-based indexing
- Identified patterns, trends, and key performance indicators within retail and sales data

### Data Cleaning and Preparation
- Handled missing values using:
  - `dropna()`
  - `fillna()`
- Removed duplicates and corrected data inconsistencies
- Renamed and reformatted columns for improved usability
- Converted data types where required for analysis
- Prepared datasets for reporting and visualisation

### Data Manipulation with Pandas
- Sorted and organised data using `sort_values()`
- Grouped and aggregated data using `groupby()`
- Applied filtering techniques to isolate specific products, regions, or sales periods
- Created calculated fields and summary tables
- Used pandas functions to transform raw data into meaningful business information

## Technologies Used
- Python
- Pandas
- Google Colab / Jupyter Notebook

## Key Learning Outcomes
Through this project, I developed practical experience in using Python for data analysis workflows, including data cleaning, manipulation, exploration, and visualisation. The project strengthened my ability to work with retail and sales datasets, apply analytical thinking, and communicate insights through both code and visual reporting.
